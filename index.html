GÜÇLÜ ALGORİTMİK TEMEL, SÜREKLİ ÖĞRENME TUTKUSU VE GERÇEK DÜNYA PROJE PRATİĞİ.

Amasya Üniversitesi Bilgisayar Mühendisliği bölümünde edindiğim güçlü teorik altyapıyı, henüz lisans sürecimdeyken gerçekleştirdiğim kurumsal stajlar ve Ar-Ge projeleriyle somut mühendislik pratiklerine dönüştürdüm.

Yazılım geliştirmeye yalnızca kod yazma pratiği olarak değil; veritabanı modellemesinden arka plan servislerine, sistem performansından altyapı güvenliğine kadar bütüncül bir problem çözme disiplini olarak yaklaşıyorum. Backend mimarileri, modern C# / .NET teknolojileri ve Unreal Engine 5 tabanlı yapay zeka sistemleri üzerine odaklanıyorum.

Yeni mezun bir bilgisayar mühendisi olarak; temiz kod (Clean Code) standartlarına özen gösteren, analitik düşünme refleksine sahip, yeni teknolojilere hızla adapte olabilen ve takım çalışmasında katma değer üreten bir yaklaşımla profesyonel yazılım ekiplerinde aktif sorumluluk almaya hazırım.

#01 06.07.2026 – 04.08.2026 KURUMSAL BT & AĞ GÜVENLİĞİ

BT ve Yazılım Geliştirme Stajyeri

BİEN YAPI ÜRÜNLERİ

Büyük ölçekli endüstriyel üretim tesisinde kurumsal siber güvenlik altyapısı, ağ topolojisi, sunucu kurulumları ve yardım masası süreçlerinde kritik teknik sorumluluklar üstlendi.

→ Kurumsal ağ altyapısındaki FortiGate güvenlik duvarında NAT kurallarını, SSL denetimini (inspection) ve web filtreleme politikalarını yapılandırdı.
→ Uygulama kontrol profilleri oluşturdu ve sistem güvenlik günlüklerini (firewall logs) düzenli olarak inceledi.
→ Zyxel çekirdek ve uç anahtarlarla (switches) fabrika ağ topolojisini haritalandırdı ve VFL fiber optik testi ile yapısal kablolama işlemlerini bizzat yürüttü.
→ Server Manager üzerinden Windows Server kurulumu, statik IP ve ana bilgisayar adı (hostname/DNS) yapılandırmalarını başarıyla gerçekleştirdi.
→ Yardım masası operasyonları sırasında iş istasyonu kurulumu, MDM uç nokta kısıtlamaları, ağ güvenlik açığı tespiti ve IP kamera yapılandırma sorunlarını çözüme kavuşturdu.
FortiGate Firewall NAT & SSL Inspection Zyxel Switching VFL Fiber Testi Windows Server MDM Yardım Masası
#02 01.07.2024 – 23.08.2024 YAZILIM MÜHENDİSLİĞİ

Yazılım Geliştirme Stajyeri

İSTİKAMET DÖKÜM A.Ş.

Endüstriyel döküm firmasının kurumsal süreçlerini dijitalleştirmek üzere ASP.NET Core, FastAPI bulut mikroservisleri, LLM karar motorları ve mobil-web entegrasyonlu yazılımlar geliştirdi.

→ ASP.NET Core MVC ve Entity Framework Core kullanarak MSSQL tabanlı bir lisans takip otomasyonu geliştirdi.
→ Yaklaşan lisans sürelerinin dolması için Background Service ve SMTP entegrasyonu ile otomatik e-posta bildirim sistemi kurdu.
→ Render platformunda FastAPI ve PostgreSQL/SQLite tabanlı bulut API servislerini devreye aldı ve Streamlit kullanarak yönetici paneli tasarladı.
→ Google Gemini LLM API'sini kural tabanlı yerel bir NLP motoruyla birleştiren, Gmail IMAP entegrasyonunu MailKit/MimeKit ile kuran hibrit bir BT Destek Karar Otomasyonu geliştirdi.
→ React.js ve Kotlin kullanarak Firebase Firestore üzerinde gerçek zamanlı ve eşzamanlı çalışan uçtan uca bir Stok Takip Sistemi geliştirdi.
ASP.NET Core MVC Entity Framework Core FastAPI Google Gemini LLM MSSQL React.js Kotlin Firebase Firestore Streamlit MailKit
